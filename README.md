# Customer Transaction Prediction

## Project Overview
A Machine Learning classification project to predict whether a bank customer will make a future transaction using historical customer data.

**Project ID:** PRCP-1003  
**Domain:** Banking

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- LightGBM, XGBoost, CatBoost
- SMOTE
- Jupyter Notebook

## Models Implemented
- Logistic Regression
- Decision Tree
- Random Forest
- Extra Trees
- XGBoost
- LightGBM
- CatBoost

## Final Model
**Optimized LightGBM**

| Metric | Score |
|---|---:|
| Accuracy | 89.49% |
| Precision | 48.20% |
| Recall | 60.70% |
| F1-score | 53.73% |
| ROC-AUC | 88.56% |
| PR-AUC | 56.53% |
